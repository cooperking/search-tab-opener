# Search Tab Opener

Import a CSV or spreadsheet, build a search URL from its columns, clean up the terms with find and replace, then open each result in its own tab.

Open the app: https://cooperking.github.io/search-tab-opener/

Everything runs in your browser. Files you import and searches you save stay on your device.

## Opening a CSV from a link

Paste a link into **Or load from a link** in step 1. These work:

- **Google Sheets:** the sheet must be shared as "Anyone with the link can view". Paste the normal sheet address.
- **GitHub:** a link to a CSV file in a repo (public repos only).
- **Dropbox:** a share link.
- **Any CSV or Excel file** on a site that allows other websites to read it.

**Copy link to this setup** gives you a link that opens this site with the CSV, website and find and replace rules already filled in. Bookmark it or add it to your home screen.

You can also put CSV files in this repo and link to them by path, for example:
https://cooperking.github.io/search-tab-opener/#csv=examples/sample.csv&tpl=https%3A%2F%2Fwww.google.com%2Fsearch%3Fq%3D%7BCompany%7D
